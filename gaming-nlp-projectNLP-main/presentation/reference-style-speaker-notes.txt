01
แนะนำโครงงานเว็บวิเคราะห์ความคิดเห็นต่อวิดีโอกีฬาบน YouTube ชื่อ SPORTS INSIGHT ใช้เป็นชื่อในการนำเสนอ ระบบเดิมใช้ Gemini API วิเคราะห์ภาษา รูปแบบภาพอ้างอิงจากไฟล์ PriceHunter ของผู้ใช้ แต่เนื้อหาเป็นของโครงงานกีฬา

02
ปัญหาที่โครงงานต้องการแก้คือการอ่านความคิดเห็นทีละข้อความทำให้เห็นภาพรวมได้ยาก บริบทเกี่ยวกับนักกีฬา ทีม หรือกรรมการอาจเปลี่ยนความหมายของข้อความ คำถามด้านขวาเป็นคำถามตั้งต้น ไม่ใช่คำพูดจากผู้ใช้ที่สัมภาษณ์

03
กลุ่มนี้เป็นผู้ใช้เป้าหมายตามลักษณะงาน ไม่ใช่ผลวิจัยความต้องการหรือหลักฐานการยอมรับจากผู้ใช้ ระบบช่วยสำรวจข้อมูล ไม่ตัดสินแทนคนทั้งหมด

04
ระบบส่งข้อความให้ Gemini จำแนก sentiment และ emotion รวมทั้งประเด็นและคำสำคัญ จากนั้นแสดงกราฟและสรุปภาษาไทย ไม่ได้โหลดหรือฝึกโมเดลภายในเครื่อง

05
นำผู้ฟังตามขั้นตอนการใช้งานจริง เริ่มค้นหาวิดีโอกีฬา เลือกคลิป แล้วกดวิเคราะห์ การเรียกวิเคราะห์ต้องมีคีย์ Gemini และต้องรอการตอบกลับจากบริการภายนอก

06
อ้างอิง README.md ระบบใช้วิดีโอหมวด Sports ส่งตัวอย่างความคิดเห็นหลักสูงสุดตามค่าตั้งต้น 100 รายการ จำกัด 2000 ตัวอักษรต่อรายการ Backend ตรวจรูปแบบ JSON และความครบถ้วนของผลสำหรับทุกความคิดเห็นก่อนคำนวณสัดส่วนและบันทึก

07
การตรวจสอบรูปแบบไม่ใช่การรับรองความแม่นยำด้านภาษา Backend ตรวจ ID ให้ครอบคลุมข้อมูล ตรวจ label ตามชุดที่อนุญาต คำนวณเปอร์เซ็นต์จากผลจริง และไม่บันทึกผลปลอมเมื่อบริการขัดข้อง หนึ่งความคิดเห็นมีได้หลายหัวข้อ สัดส่วนหัวข้อจึงอาจรวมเกิน 100 เปอร์เซ็นต์

08
สถาปัตยกรรมอ้างอิง README ของโปรเจกต์ Frontend ติดต่อ FastAPI ซึ่งประสานงาน YouTube และ Gemini ก่อนจัดเก็บผลใน SQLite API keys ไม่ถูกส่งให้ frontend

09
ภาพจาก presentation/assets/dashboard.png เป็นภาพที่บันทึกไว้ในโปรเจกต์ ไม่ใช่ระบบสดขณะนำเสนอ อธิบายส่วนค้นหา รายการวิดีโอ และการเลือกวิดีโอเพื่อวิเคราะห์

10
ภาพตัดจาก analysis.png ในโปรเจกต์ กราฟซ้ายแสดง sentiment และด้านขวาแสดง emotion ผลในภาพคำนวณจากตัวอย่าง 27 ความคิดเห็น เป็นภาพสาธิตการทำงาน ไม่ใช่ผลประเมินความแม่นยำ

11
ที่มา presentation/evidence.json บันทึก 27 กันยายน 2569 วิดีโอจาก T Sports 7 จำนวนตัวอย่าง 27 รายการ สัดส่วน 51.9, 14.8, 33.3 เปอร์เซ็นต์ตามผลระบบ ห้ามตีความเป็นค่าความแม่นยำ หรือสรุปแทนกลุ่มผู้ชมทั้งหมด

12
ไม่รวมทุก reply และไม่ใช่การสุ่มตัวอย่างแทนประชากร ยังไม่มีผลประเมินกับชุดข้อมูลที่มนุษย์ติดป้ายกำกับ ความถูกต้องของโครงสร้างข้อมูลแยกจากความถูกต้องด้านการตีความภาษา

13
ทั้งหมดเป็นแผนพัฒนาต่อ ไม่ใช่ผลการประเมินที่ทำแล้ว ควรจัดชุดอ้างอิงให้ครอบคลุมบริบทกีฬาและภาษา ใช้ผู้ประเมินมากกว่าหนึ่งคน วิเคราะห์ข้อผิดพลาด และประเมินประสบการณ์การใช้งานจริง

14
สรุปว่าโครงงานช่วยจัดกลุ่มและแสดงภาพรวมความคิดเห็นให้สำรวจต่อได้ เปิดช่วงคำถาม แหล่งเนื้อหา: README.md, presentation/evidence.json และภาพใน presentation/assets รูปแบบอ้างอิงจาก PriceHunter PDF ที่ผู้ใช้ให้ ไม่ได้นำข้อกล่าวอ้างหรือข้อมูลธุรกิจของเอกสารนั้นมาใช้
