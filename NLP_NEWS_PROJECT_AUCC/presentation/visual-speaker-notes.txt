01
โครงงานเว็บวิเคราะห์ความคิดเห็นต่อวิดีโอกีฬาบน YouTube ใช้ Gemini จำแนกความรู้สึก อารมณ์ และประเด็นที่ผู้ชมกล่าวถึง ภาพเป็นหน้าจอที่บันทึกไว้ในโปรเจกต์เมื่อ 27 กันยายน 2569

02
ข้อความในหน้านี้เป็นตัวอย่างสมมติ ไม่ใช่ข้อความที่ดึงจากวิดีโอ ปัญหาคือการอ่านทีละความคิดเห็นทำให้เห็นภาพรวมได้ยาก ระบบจึงช่วยจัดกลุ่มและสรุปให้สำรวจต่อได้

03
ระบบค้นหาวิดีโอหมวด Sports ผ่าน YouTube API แล้วดึงความคิดเห็นหลัก ส่งข้อความตัวอย่างให้ Gemini และตรวจสอบข้อมูลก่อนบันทึกและแสดงผล ค่าเริ่มต้นวิเคราะห์ไม่เกิน 100 ความคิดเห็นต่อรอบ ไม่รวมทุก reply

04
ภาพหน้าจอจริงที่จัดเก็บไว้ในโฟลเดอร์ assets แสดงการค้นหาและเลือกวิดีโอ ผู้ใช้เลือกคลิปแล้วเรียกการวิเคราะห์ ภาพนี้เป็นภาพบันทึก ไม่ใช่ข้อมูลสดขณะนำเสนอ

05
กราฟซ้ายแสดงสัดส่วน sentiment ส่วนกราฟขวาแสดงอารมณ์หลัก ผลจากภาพตัวอย่างมี 27 ความคิดเห็น ใช้เพื่อสาธิตการแสดงผล ไม่ใช่ผลประเมินความแม่นยำของโมเดล

06
อ้างอิง presentation/evidence.json และภาพ analysis.png ที่บันทึกในโปรเจกต์ ตัวอย่างวิดีโอจาก T Sports 7 บันทึกวันที่ 27 กันยายน 2569 เชิงบวก 51.9 เปอร์เซ็นต์ เป็นกลาง 14.8 เปอร์เซ็นต์ และเชิงลบ 33.3 เปอร์เซ็นต์ ตัวเลขนี้เป็นผลจำแนกของระบบ ไม่ใช่ความแม่นยำและไม่ควรสรุปแทนผู้ชมทั้งหมด

07
Gemini ส่งผลแบบ structured JSON ครอบคลุม sentiment, emotion, topics, keywords และสรุปภาษาไทย หนึ่งความคิดเห็นอาจมีหลายประเด็น สัดส่วนหัวข้อจึงอาจรวมเกิน 100 เปอร์เซ็นต์ จำนวนคำสำคัญนับจากความคิดเห็นจริงตามวิธีในระบบ

08
React และ Vite เป็น frontend ส่วน FastAPI ประสาน YouTube API และ Gemini API ตรวจสอบคำตอบก่อนคำนวณและจัดเก็บด้วย SQLite คีย์ API อยู่ฝั่ง backend ระบบไม่โหลดโมเดลมารันในเครื่อง อ้างอิง README.md และซอร์สโค้ดของโปรเจกต์

09
ข้อมูลเป็นตัวอย่างความคิดเห็นหลักสูงสุดตามค่าตั้งต้น 100 รายการ ไม่ใช่การสุ่มแทนผู้ชมทั้งหมด โมเดลอาจตีความคำประชดหรือศัพท์กีฬาไม่ตรงบริบท ยังไม่มีผลประเมินความแม่นยำกับชุดข้อมูลที่มนุษย์ติดป้ายกำกับ แผนต่อไปคือสร้างชุดอ้างอิง ประเมิน Macro-F1 และทดสอบการใช้งาน

10
ปิดการนำเสนอด้วยคุณค่าของโครงงาน คือช่วยสำรวจความคิดเห็นและสื่อสารภาพรวมได้ง่ายขึ้น เปิดให้ถามเรื่องขอบเขตข้อมูล การตรวจสอบคำตอบ และแผนประเมินคุณภาพ แหล่งข้อมูลของสไลด์: README.md, presentation/evidence.json และภาพหน้าจอใน presentation/assets รายละเอียดภาพและข้อจำกัดอยู่ในโน้ตแต่ละหน้า
